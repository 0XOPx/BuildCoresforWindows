# Security Policy

## Supported Versions

The table below details which versions of BuildCoresforWindows currently receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| < 1.0   | :question:         |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please open a public issue on this repository. 

When creating the issue, please include:
1. A clear description of the vulnerability.
2. Steps or a brief explanation on how to reproduce it.
3. Any potential impact it might have on the application.

Thank you for helping keep this project secure!
