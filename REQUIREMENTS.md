## System Requirements

* **Operating System:** Windows 10 (Version 1809 or above).
  * *Supported on Windows Server 2016 or above also, but you aren't gonna be using this on a server bro 🥀🥀🥀*
  * **Windows only:** No macOS, no Linux. This app is built purely on native Windows Forms, not heavy cross-platform frameworks like Avalonia that bundle a ton of bloat.
* **Component Dependency:** CefSharp runtime (standard with the minimum Windows versions listed above).
* **.NET** .NET Framework 4.8 - you can get it from either getting Visual Studio or getting it via Windows Features or [the site here](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48)
